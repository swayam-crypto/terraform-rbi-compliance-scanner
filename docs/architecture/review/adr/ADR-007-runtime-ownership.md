# ADR-007: Runtime Ownership

**Status:** Proposed

**Date:** 2026-08-22

---

# Context

The platform currently contains two primary resource models:

- ResolvedResource
- CanonicalResource

The long-term runtime ownership has not yet been formally defined.

---

# Decision

Pending.

The architecture review has identified runtime ownership as a major architectural decision.

No implementation changes are recommended until this decision has been formally documented.

---

# Consequences

Once resolved, this decision will determine:

- Runtime model
- Graph ownership
- Rule execution
- Attack analysis
- Future runtime evolution
